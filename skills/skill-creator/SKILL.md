# Skill Creator Skill
## When to Use
When you need to create a new skill for GatherAgent.
## Procedure
1. Determine skill name and description (<=60 chars)
2. Create directory under skills/ with SKILL.md
3. Follow GatherAgent skill standards
4. Test with `gather skills validate <name>`
